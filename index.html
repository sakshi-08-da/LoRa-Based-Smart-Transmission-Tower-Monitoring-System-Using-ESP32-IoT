⚡ POWER CONSERVATION & VOLTAGE REGULATION
  • LM2596 Buck Converter: Steps down 12V tower battery supply to stable 5V DC for ESP32 VIN, ACS712, and digital sensors.
  • SX1278 LoRa 3.3V Requirement: VCC pin MUST be powered directly from the ESP32 internal 3.3V LDO regulator rail. Connecting 5V will destroy the RF IC.
  • Common Ground Reference: All sensor GND pins, buck converter OUT- pin, and ESP32 GND must be joined to a single ground plane.
📡 BUS ISOLATION & ESP32 ADC CONSTRAINTS
  • Analog Channel Selection: ZMPT101B Voltage Sensor uses GPIO 27 (ADC2 CH7, read before active Wi-Fi frame transmission) and ACS712 Current Sensor uses GPIO 32 (ADC1 CH4).
  • SPI Interrupt Pin (DIO0): GPIO 2 serves as the hardware interrupt line notifying the ESP32 CPU when a LoRa packet has finished sending/receiving.
  • I2C Addresses: MPU6050 Gyro uses address 0x68 while SSD1306 OLED uses address 0x3C on the shared I2C bus (GPIO 21/22).

ACADEMIC SEMINAR PROJECT DOCUMENTATION

        
        
1. Introduction

        
High-voltage electrical transmission towers form the backbone of modern power distribution grids. Ensuring their structural stability and electrical line integrity is critical to preventing catastrophic power outages, wildfire hazards, and infrastructure collapses. This project presents a wireless IoT monitoring framework utilizing ESP32 microcontrollers and LoRa (Long Range) Point-to-Point (P2P) radio telemetry.


        
2. Problem Statement

        
Traditional grid inspection relies heavily on manual physical line patrols and scheduled maintenance, which are slow, labor-intensive, hazardous in remote mountainous terrains, and unable to provide real-time alerts during sudden structural failure events such as tower tilt, line overheating, or flash fires.


        
3. Proposed System Architecture

        
The proposed system installs sensor nodes on main transmission towers (Tower 1), gathering inclination data (MPU6050), structural vibration (SW-420), fire presence, AC line voltage (ZMPT101B calibrated for 230V AC Indian Mains reference), and AC load current (ACS712 True RMS with < 0.12A deadband). Sensor parameters are processed locally by an ESP32 and transmitted via a direct RF telemetry link to an IoT Receiver Gateway (Tower 2). The gateway renders local telemetry on a 0.96" SSD1306 OLED display and publishes JSON packets via Wi-Fi to a HiveMQ Cloud MQTT Broker for cloud visualization.


        
4. LoRa P2P vs LoRaWAN

        
LoRa P2P: Direct node-to-node RF communication without network servers or gateway overhead. Ideal for localized line-to-line monitoring between adjacent transmission towers.

        
LoRaWAN: A star-of-stars network architecture using central gateways and Network Servers (e.g. TTN). Future expansion can integrate a LoRaWAN gateway for multi-mile regional grid scaling.
